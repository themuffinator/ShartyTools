# Empty project template

Copy `jam.sharty.json` into your own jam workspace. Create a sibling `content/` directory containing your submissions at game-relative paths (for example `content/maps/intro.bsp`). Open the copied project, discover maps and edit the metadata. Add read-only game reference roots as needed.

This is an intentionally empty starting project, not a playable sample jam. It will fail the “at least one map” build check until you add content. Tests generate their own synthetic fixtures; no copyrighted Quake assets are included here.
